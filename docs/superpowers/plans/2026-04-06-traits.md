# Traits (Cechy) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Cechy" traits section to character cards and the edit dialog, storing `[{ name, value }]` on the Firestore character document.

**Architecture:** Two files are modified — `Character.jsx` renders traits as chips below the money row; `EditCharacterDialog.jsx` lets admins add (via freeSolo Autocomplete), edit values, and delete traits inline. Trait names for the combobox are sourced from the React Query cache via `queryClient.getQueriesData(["characters"])` — no extra Firestore calls.

**Tech Stack:** React 18, MUI v5 (`Chip`, `Autocomplete`, `TextField`, `IconButton`), React Query v3, Firebase Firestore

Collect existing trait names from React Query cache (add after `const queryClient = useQueryClient();`):

```jsx
const existingTraitNames = [
  ...new Set(
    queryClient
      .getQueriesData(["characters"])
      .flatMap(([, data]) => (data || []))
      .flatMap((c) => (c.traits || []).map((t) => t.name))
  ),
];
```

After the existing traits list (after the closing `})}` of the `.map()`), add the add-row:

```jsx
<Box display="flex" alignItems="flex-end" gap={1} sx={{ mt: 1 }}>
  <Autocomplete
    freeSolo
    options={existingTraitNames}
    value={newTraitName}
    onChange={(e, value) => setNewTraitName(value || '')}
    onInputChange={(e, value) => setNewTraitName(value || '')}
    renderInput={(params) => (
      <TextField
        {...params}
        variant="standard"
        placeholder="Nowa cecha..."
        size="small"
      />
    )}
    size="small"
    sx={{ flex: 1 }}
  />
  <Input
    value={newTraitValue}
    onChange={(e) => setNewTraitValue(e.target.value)}
    placeholder="Wartość"
    sx={{ width: "64px" }}
  />
  <IconButton
    aria-label="dodaj cechę"
    size="small"
    disabled={!newTraitName.trim()}
    onClick={() => {
      setCharacter((prev) => ({
        ...prev,
        traits: [
          ...(prev.traits || []),
          { name: newTraitName.trim(), value: newTraitValue },
        ],
      }));
      setNewTraitName('');
      setNewTraitValue('');
    }}
  >
    <AddIcon fontSize="small" />
  </IconButton>
</Box>
```
